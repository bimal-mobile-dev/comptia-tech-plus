# CompTIA Tech+ (FC0-U71) Study Resources

Material and resources for pursuing CompTIA Tech+ certification — built from the current **FC0-U71 (V6) exam objectives**, current as of September 2026.

## A note on currency

**FC0-U71 replaced ITF+ (FC0-U61)** as CompTIA's entry-level IT certification, and carries the new "Tech+" name rather than "IT Fundamentals+." If a study resource still says "ITF+" or uses the FC0-U61 exam code, it's the retired predecessor — the content overlaps heavily but domain names and a few topics (notably generative AI awareness, now explicit in the Applications and Software domain) have been refreshed. Also note: unlike most CompTIA certifications, **Tech+ does not expire** — it's a one-time "certification for life," so there's no recertification cycle to plan around once you pass.

## Overview

- **Who is it for?** The true entry point into CompTIA's certification ladder — for complete beginners, students exploring IT as a career, career changers, or non-technical professionals (sales, marketing, finance) who need working technology literacy. CompTIA explicitly designs it as a pre-professional stepping stone toward A+ and beyond, not a standalone career credential for IT roles.
- **No prerequisites.** Tech+ assumes no prior IT background — if you already have hands-on IT experience, you'll likely find this exam straightforward and may want to skip straight to A+.
- **Exam format**: multiple-choice, scaled scoring with **650 (out of 100–900) required to pass**.
- **Domain weights (FC0-U71 V6):**

| Domain | Weight |
|---|---|
| Tech Concepts and Terminology | 13% |
| Infrastructure | 24% |
| Applications and Software | 18% |
| Software Development Concepts | 13% |
| Data and Database Fundamentals | 13% |
| Security | 19% |

- **Test-taking strategies**
  - Infrastructure (24%) and Security (19%) together are 43% of the exam — prioritize hardware/networking basics and core security concepts before the smaller domains
  - Tech Concepts and Terminology carries the lowest individual weight (13%), but it establishes the vocabulary (binary/hex, units of measure, troubleshooting methodology) used throughout every other domain — don't skip it just because it's lightly weighted
  - This exam rewards broad conceptual recognition over deep hands-on skill — you're expected to correctly identify and explain concepts (what a NIC does, what SaaS means), not configure enterprise systems
