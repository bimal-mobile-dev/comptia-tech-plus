- **18% weighting.** Covers operating systems, common application types, and cloud service models

## Operating systems

- **Major OS families**: Windows, macOS, Linux, and mobile operating systems (iOS, Android) — recognizing their general use cases and basic differences rather than deep configuration
- **Common OS functions**: file management, user accounts, and basic system settings

## Application types and productivity software

- **Common software categories**: productivity software (word processing, spreadsheets), collaboration tools, and web browsers — recognizing what category a described application belongs to and its typical use case
- **Generative AI tools**: a newly explicit topic in FC0-U71 — basic awareness of generative AI applications and their appropriate/inappropriate use in a professional context, reflecting how mainstream AI tool usage has become since the prior ITF+ version

## Cloud computing service models

- **IaaS, PaaS, and SaaS**: introductory-level recognition of the three cloud service models and their basic differences (e.g., SaaS delivers a complete application, IaaS delivers raw infrastructure) — the same core vocabulary developed much further in CCSP and Security+, introduced here at its simplest form
