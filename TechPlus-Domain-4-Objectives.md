- **13% weighting.** A conceptual introduction to programming logic — no coding ability is required, but recognizing fundamental building blocks is expected

## Programming logic fundamentals

- **Variables and data types**: understanding that a variable stores a value, and that different data types (text, number, true/false) hold different kinds of values
- **Control structures**: conditionals (if/else logic) and loops (repeating an action) — the basic logical building blocks of any program, recognized conceptually rather than written in actual code

## Programming concepts and software development

- **Common programming languages**: general awareness of different language types (e.g., compiled vs. interpreted) and their typical use cases, without needing to write in any of them
- **Software development lifecycle basics**: a conceptual introduction to how software moves from an idea through development, testing, and release — a much lighter version of the SDLC concepts covered in depth within CISSP Domain 8 and the SecurityX/PenTest+ application security content
