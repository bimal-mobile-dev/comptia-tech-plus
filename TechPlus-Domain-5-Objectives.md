- **13% weighting.** Introductory database concepts and how data is organized, stored, and retrieved

## Database concepts

- **Relational database basics**: tables, rows, and columns as the fundamental structure of a relational database — recognizing how data is organized rather than designing a schema
- **Database types**: relational vs. non-relational (NoSQL) databases at a conceptual level — knowing they exist and serve different kinds of data needs, without deep technical comparison

## Data structures and basic querying

- **Common data formats**: recognizing structured data formats used to exchange information between systems
- **Basic query concepts**: understanding that a query retrieves specific data from a database based on defined criteria — introductory awareness rather than writing actual SQL, which is developed further at more advanced certification levels (e.g., data analytics-focused credentials)
